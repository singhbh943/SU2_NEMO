NEMO / MUTATION++ DIMENSIONALIZATION CONTRACT
==============================================

Parent base:
e65a9035899253f1c42c3e75ce3ed85b08d83171

Problem
-------
The NEMO Mutation++ interface currently passes thermochemical states
directly to Mutation++ and stores returned transport / thermodynamic
properties without a complete SU2 reference-value conversion layer.

Allowing a non-dimensional SU2 reference mode would therefore mix
non-dimensional flow variables with dimensional Mutation++ properties.

This is broader than wall heat-flux reporting alone.  A local
multiplication by Heat_Flux_Ref would not repair thermodynamics,
chemistry, viscosity, diffusion, species enthalpy, thermal
conductivity, or Stefan-Maxwell transport consistently.

Production contract
-------------------
NEMO + Mutation++ currently requires:

  REF_DIMENSIONALIZATION= DIMENSIONAL

Non-dimensional reference modes fail explicitly in:

  CNEMOEulerSolver::SetNondimensionalization()

No change was made to the NEMO wall heat-flux expression.
