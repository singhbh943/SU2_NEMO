Problem
-------
Mutation++ Stefan-Maxwell transport instantiated header-only Eigen QR code
inside libmutation__.so while SU2_CFD also exported the same weak Eigen
template symbol under a different compilation environment.

Before isolation, AIR11 crashed before iteration 0 inside:

  Eigen::ColPivHouseholderQR<MatrixXd>::computeInPlace()

called from:

  Mutation::Transport::stefanMaxwell(...)

Fix
---
Mutation++ shared library target uses:

  -fvisibility-inlines-hidden
  -Wl,-Bsymbolic-functions

The first reduces preemptible inline/template symbols.
The second binds internal shared-library function references locally.
Both are retained because the Eigen QR weak symbol remains dynamically
visible after compilation.
